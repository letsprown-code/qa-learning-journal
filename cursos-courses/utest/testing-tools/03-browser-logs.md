## O que são logs / What logs are
🇧🇷 Registros que o site ou o app gera enquanto funciona. Os desenvolvedores usam para achar a causa do bug. 🇺🇸 Entries generated by a site/app while it runs; developers use them for debugging.

| Tipo / Type | 🇧🇷 Quando | 🇺🇸 When |
|---|---|---|
| **Console do navegador / Browser console** | testando **site** (requisições, JavaScript, CSS, erros de segurança) | testing a **website** |
| **Log do aparelho / Mobile device** | testando **app** no celular | testing a **mobile app** |
| **Rede / Network (HAR, proxy)** | só em alguns ciclos, quando pedirem | some cycles only |

## Regras / Rules
| 🇧🇷 | 🇺🇸 |
|---|---|
| **Limpe os logs antigos** antes de começar | **Clear old logs** first |
| Salve em **.txt** (HAR em **.har**) | Save as **.txt** (HAR as **.har**) |
| **Reproduza o bug** enquanto o log grava; ele precisa ter o tráfego do site ou app testado | **Reproduce the bug** while logging |
| **Timestamps** no começo de cada linha (exceto Safari) | **Timestamps** on each line (except Safari) |
| O log de console precisa ter a linha <code>Navigated to</code> com o site de teste | Console log must include <code>Navigated to</code> + test site |

Exemplo de linha válida / Valid line example: <code>18:32:30.854 Navigated to https://www.utest.com</code>

## HAR (tráfego de rede no navegador / browser network traffic)
- 🇧🇷 **HAR = HTTP Archive**: mostra a conversa entre o navegador e o site. **Só envie se o TTL, TE ou TSM pedir.** 🇺🇸 Upload **only if TTL/TE/TSM asks**.
- ⚠️ 🇧🇷 HAR guarda **dados sensíveis** (usuário, senha, cartão, IBAN). Apague tudo isso do arquivo antes de enviar. Feche as outras abas antes de gravar. 🇺🇸 HAR contains **sensitive data**; remove it before uploading; close other tabs.
- 🇧🇷 Chrome: DevTools → **Network** → **Preserve log** → 🚫 limpar → reproduzir → botão direito → **Save all as HAR with content** (ou o botão de download). Para ver o **status code**: clique na linha → Headers → General (ex.: 200 OK, 400 Bad Request). O **funil** filtra por palavra. 🇺🇸 Network → Preserve log → clear → reproduce → **Save all as HAR with content**.
- 🇧🇷 Firefox: <code>Ctrl+Shift+E</code> → Network → ⚙️ **Persist Logs** → 🗑️ → reproduzir → **Save All As HAR**.

## Celular / Mobile browser (remote debugging)
- 🇧🇷 **Android** (Chrome ou Firefox): ative **Opções do desenvolvedor** (toque 7× no Número da versão) → **Depuração USB** → cabo USB → no computador, <code>adb start-server</code> (Platform-Tools) → no Chrome do computador abra <code>chrome://inspect#devices</code> → **Inspect** na aba do site → mesmos passos do console. 🇺🇸 Enable USB debugging → <code>chrome://inspect</code> → Inspect.
- 🇧🇷 **iOS**: só via **Safari + Mac** (Web Inspector), também para Chrome e Firefox do iPhone. 🇺🇸 **iOS**: via **Mac + Safari** Web Inspector.
