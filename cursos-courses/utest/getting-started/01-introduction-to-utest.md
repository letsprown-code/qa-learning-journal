## Siglas essenciais / Key acronyms

| Sigla / Acronym | 🇧🇷 Significado | 🇺🇸 Meaning |
|---|---|---|
| TTL | Test Team Lead: principal contato do tester; revisa bugs e casos de teste | Test Team Lead: tester's main contact; reviews bugs and test cases |
| TE | Test Engineer: monta o ciclo e a equipe | Test Engineer: builds the cycle and team |
| TSM | Testing Services Manager: trabalha direto com o cliente | Testing Services Manager: works directly with the client |
| CM | Community Manager: gestão da comunidade | Community Manager |
| Slot | Vaga reservada num ciclo para um perfil específico (aparelho, país, sistema) | Reserved position in a cycle for a specific profile |
| SRS | Special Requirement Survey: pesquisa para recrutar testers | Survey used to recruit testers |
| KI | Known Issue: bug já conhecido; confira antes de reportar para evitar duplicado | Known issue; check before reporting to avoid duplicates |
| BFV | Bug Fix Verification: verificar se o bug foi corrigido | Verify a reported bug was fixed |
| IR | Info Request: pedido de mais informações no seu relatório | Request for more info on your report |
| NDA | Acordo de confidencialidade | Non-Disclosure Agreement |
| Placeholder | Relatório incompleto enviado só para "guardar lugar" (**proibido**) | Incomplete report submitted to reserve a spot (**forbidden**) |

### Motivos de rejeição / Rejection reasons
- **WAD** (Working As Designed): funciona como projetado / behaves as designed
- **DUP** (Duplicate): já reportado ou é um Known Issue / already reported or a Known Issue
- **OOS** (Out Of Scope): fora do escopo do ciclo / outside the cycle's scope
- **DNFI** (Did Not Follow Instructions): não seguiu as instruções / didn't follow instructions
- **INF** (Need more info): não respondeu ao pedido de informação / didn't answer the info request

### Aprovação / Approval
- Somewhat Valuable, Very Valuable, Exceptionally Valuable; **WNF** (Won't Fix) = bug válido que o cliente não vai corrigir / valid bug the client won't fix.

### Níveis de tester / Tester tiers
Unrated → Rated → Proven → Bronze → Silver → Gold
