## O que é um projeto / What a project is
🇧🇷 Um **evento com duração, requisitos e pagamento bem definidos**, feito sob demanda para um cliente. Quem cumpre as tarefas especiais das instruções recebe um **pagamento garantido**. 🇺🇸 An **event with defined duration, requirements and payout**; special tasks → **guaranteed payout**.

~~~mermaid
flowchart LR
    S[Pesquisa/survey do<br/>Staffing Specialist] --> A[Avaliação: país, idade,<br/>idioma, aparelhos...]
    A -- atende tudo --> I[Convite por e-mail]
    A -- não atende --> N[Tente os próximos!]
    I --> C[Confirmar respondendo o e-mail]
    C --> T[Testar: chat do ciclo / Discord]
~~~

- 🇧🇷 **Como entrar:** responder a **pesquisa** enviada pelo Staffing Specialist (ou Project Coordinator). Responder **não garante** vaga, mas vale sempre se candidatar. 🇺🇸 Fill in the **survey**; not guaranteed.
- 🇧🇷 **Selecionada?** Chega um **e-mail** com tudo sobre o projeto. Leia o e-mail com frequência e confirme respondendo. 🇺🇸 Email with all details; confirm by replying.
- 🇧🇷 **Discord da Test IO:** use o **mesmo nome do perfil de testador** para ser encontrada. 🇺🇸 Use the same screenname on Discord.

## Tipos de projeto / Project types
| Tipo / Type | 🇧🇷 |
|---|---|
| **Hardware Testing** | testar aparelhos físicos (celular, tablet, IoT); a empresa **envia o aparelho** |
| **In-Field Testing** | testar no mundo real: GPS, atividade física, pagamento em loja |
| **Digital Identity Verification** | verificar identidade, ex.: passaporte com NFC num app |
| **Background Testing** | deixar o app rodando em segundo plano por dias |
| **Performance Testing** | acompanhar o desempenho do app e coletar logs |

## Dados pessoais e NDA / Personal data & NDA
- 🇧🇷 Alguns projetos pedem **endereço** (para enviar hardware; **não aceitam caixa postal, endereço falso ou de outra pessoa**) ou os **últimos dígitos do cartão** (para pagamento em loja). Tudo vem escrito nas instruções. Se não se sentir à vontade, **recuse o convite**. 🇺🇸 Address for hardware (no PO boxes/fake), card last digits; decline if uncomfortable.
- 🇧🇷 Mande dados **só para o Staffing Specialist**, nunca para outros testadores. A Test IO e o cliente tratam os dados com respeito e **não vendem para ninguém**. Os dados ficam guardados até o fim do projeto, e você é avisada quando são apagados. 🇺🇸 Only to the Staffing Specialist; data not sold; deleted at the end.
- 🇧🇷 **NDA:** nada do projeto pode ser compartilhado com quem está fora dele, nem amigos nem família. Às vezes é preciso **assinar e enviar** o NDA. 🇺🇸 NDA: no sharing outside the project.
- 🇧🇷 Pedidos de informação do cliente: responda em até **24 h**. Alguns projetos exigem **varredura de antivírus** antes. 🇺🇸 Info requests within **24 h**; antivirus scan may be mandatory.
