# Glossário · Glossary

Termos de QA em português e inglês, com explicação simples. Vou completando conforme estudo.
QA terms in Portuguese and English, with plain explanations. Updated as I study.

| Português | English | O que significa · Meaning |
| --- | --- | --- |
| Bug, defeito | Bug, defect | Algo que não funciona como deveria · Something that does not work as intended |
| Bug funcional | Functional bug | Uma ação não dá o resultado esperado · An action does not give the expected result |
| Bug de conteúdo | Content bug | Texto, imagem, link ou dado faltando ou quebrado · Missing or broken text, image, link or data |
| Bug visual | Visual bug | Problema de aparência: desalinhado, cortado, sobreposto · Appearance problem: misaligned, cut off, overlapping |
| Sugestão de usabilidade | Usability suggestion | Ideia para facilitar o uso · Idea to make the product easier to use |
| Gravidade | Severity | Quanto o bug atrapalha · How much the bug affects use |
| Baixa / Alta / Crítica | Low / High / Critical | Níveis de gravidade no Test IO · Severity levels on Test IO |
| Contorno, solução alternativa | Workaround | Outro jeito de conseguir fazer a tarefa · Another way to complete the task |
| Bloqueador | Showstopper | Bug que impede continuar o processo principal · Bug that stops the main process |
| Teste exploratório | Exploratory testing | Testar usando o produto livremente, como um usuário real · Testing by freely using the product like a real user |
| Reprodução de bug | Bug reproduction | Repetir os passos para confirmar que o bug acontece · Repeating the steps to confirm a bug happens |
| Passos para reproduzir | Steps to reproduce | Lista de ações que levam ao bug · List of actions that lead to the bug |
| Resultado esperado | Expected result | O que deveria acontecer · What should happen |
| Resultado atual | Actual result | O que aconteceu de fato · What actually happened |
| Anexo | Attachment | Print ou gravação de tela que prova o bug · Screenshot or screen recording that proves the bug |
| Gravação de tela | Screencast | Vídeo da tela mostrando o bug · Video of the screen showing the bug |
| Captura de tela, print | Screenshot | Imagem da tela · Image of the screen |
| Dica flutuante | Tooltip | Texto que aparece ao passar o mouse · Text shown on hover |
| Trilha de navegação | Breadcrumb | Caminho de links no topo da página (Início > Categoria > Produto) · Link path at the top of a page |
| Rodapé / Cabeçalho | Footer / Header | Parte de baixo / de cima do site · Bottom / top of the site |
| Layout responsivo | Responsive design | Tela que se adapta ao tamanho do aparelho · Layout that adapts to the device size |
| Erro 404 | 404 error | Página não encontrada · Page not found |
| Redirecionamento | Redirection | Quando um link leva para outra página · When a link sends you to another page |
