# QA Learning Journal · Diário de estudos de QA

**Português (Brasil)** | [English below](#english)

Este repositório é o meu diário de estudos de **QA (garantia de qualidade de software)** e **crowdtesting**, o trabalho de testar sites e aplicativos de forma remota para empresas do mundo todo.

Aqui eu registro, com as minhas palavras, o que aprendo nos cursos que faço, organizados pela plataforma onde cada curso foi feito. Também guardo exemplos práticos de relatórios de bug.

As notas são resumos próprios. Os materiais originais pertencem a cada plataforma, e os links levam até eles.

## Como este repositório está organizado

```
qa-learning-journal/
├── cursos-courses/            Cursos, separados por plataforma
│   └── test-io/               Plataforma onde o curso foi feito
│       └── exploratory-testing/   Um curso
│           ├── 01-bug-types.md        Nota de estudo do módulo
│           └── 01-bug-types-quiz.md   Quiz comentado do módulo
├── plataformas-platforms/     Como funciona cada plataforma de testes
├── glossario-glossary.md      Termos de QA em português e inglês
├── templates/                 Modelos de relatório de bug
└── exemplos-examples/         Bugs que eu encontrei praticando
```

**Regra para cursos novos:** `cursos-courses/<plataforma>/<curso>/<número>-<módulo>.md`, com nomes em letras minúsculas e palavras separadas por hífen. Toda nota começa com uma tabela que diz a plataforma, o curso, o módulo, a situação e o link da fonte original.

Algumas pastas só aparecem no GitHub quando recebem o primeiro arquivo.

## Acessibilidade

Quero que qualquer pessoa consiga ler este material. Por isso:

- uso linguagem simples e explico cada termo técnico na primeira vez que ele aparece;
- organizo os textos com títulos, listas e tabelas com cabeçalho, para facilitar a leitura com leitores de tela;
- toda imagem tem descrição em texto (texto alternativo);
- nenhuma informação depende só de cor ou de ícone;
- os links dizem para onde levam.

Se algo estiver difícil de entender, abra uma *issue* (um pedido ou comentário aqui no GitHub).

## English

This repository is my learning journal for **QA (software quality assurance)** and **crowdtesting**: remote testing of websites and apps for companies around the world.

I write down, in my own words, what I learn in each course, organized by the platform where I took it, plus practice bug reports. The notes are my own summaries; the original materials belong to each platform, and the links point to them.

### How this repository is organized

| Folder or file | What it contains |
| --- | --- |
| `cursos-courses/` | Courses, grouped by platform, then by course, with one note per module |
| `plataformas-platforms/` | How each testing platform works |
| [`glossario-glossary.md`](glossario-glossary.md) | QA terms in Portuguese and English |
| `templates/` | Bug report templates |
| `exemplos-examples/` | Bugs I found while practicing |

**Rule for new courses:** `cursos-courses/<platform>/<course>/<number>-<module>.md`, lowercase with hyphens. Every note starts with a table naming the platform, course, module, status and original source.

### Accessibility

Plain language, every technical term explained the first time it appears, clear headings, tables with headers, text descriptions for every image, no information conveyed by color or icons alone, and descriptive links. If something is hard to understand, please open an issue.
